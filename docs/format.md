# ソースの整形

js・css・html の見た目(字下げ・引用符・改行)は、整形の道具 Prettier で自動でそろえます。手でそろえません。2026-11-07 決定。

## 決まり

| 項目 | 決まり | 理由 |
| --- | --- | --- |
| 道具 | Prettier | 一番広く使われている。開発環境にもある |
| 設定 | リポジトリの `.prettierrc.json`(公開しない) | 誰が整形しても同じ形になる。設定を手で渡さない |
| 引用符 | 単一 `'` | Airbnb・Google・Standard の書き方の決まりがそろって単一 |
| 1行の長さ | 100字の目安(日本語は1字を2字と数える) | Airbnb と同じ。日本語のログの文が多く、80字では折り返しが多すぎる |
| 末尾のカンマ | 複数行の時は全部に付ける | Prettier 3 の標準。足した時の差分が1行で済む |
| ほか | Prettier の標準(字下げ2つ、セミコロンあり、改行は LF、HTML の空白は CSS に合わせる) | 決める物を減らす |
| 文字と改行 | `.editorconfig`: UTF-8・LF・最後に改行・行末の空白を消す | エディタで開いた時も同じになる |

## 整形しない物(`.prettierignore`)

| 物 | 理由 |
| --- | --- |
| `.svg` | 絵のデータ。手で整えた形を残す |
| `.json` | データは「1行に1件」の形を守る(`index-data.json` など)。整形すると1件が何行にも分かれる |
| Markdown(`docs/` など) | 日本語の表の幅をそろえて、差分が大きくなる |

## 使い方

- 変えた js・css・html は、公開する前に必ず整形します:
  `node /opt/node-tools/node_modules/prettier/bin/prettier.cjs --write <ファイル>`
  (設定はリポジトリの一番上から自動で読む。リポジトリの外から動かす時も、ファイルの場所で決まる)
- 整形だけの変更と、中身の変更は、別のコミットにします(差分を読みやすくするため)。
- HTML の整形でエラーが出たら、HTML の書き間違いです。直してから公開します。
