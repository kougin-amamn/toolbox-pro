# ページの土台(ヘッダのボタン・読み込み確認) 設計書

2026-11-07 作成、同日 ヘッダを隠すページを追加

## 概要

全ページ(ツール45・ランチャー3・一覧)の HTML に同じ物が貼ってあった2つ(ヘッダのテーマ・デバッグのボタン、共通ファイルの読み込み確認)を短くし、HTML の量を減らして読みやすくする。

## 課題と方針

| 課題 | 方針 |
| --- | --- |
| テーマとデバッグのボタン(1ページ約25行)が全ページに同じ形で貼ってある | `site.js` が足す。環境情報・カラーテーマと同じ作り(`addHeaderButton`)にまとめる |
| 読み込み確認(ツール1ページ約55行)が `log` と `ToolKit` の代わりを作っている | 代わりは作らず、案内を出すだけにする。共通ファイルが無ければツールは動かせないので、代わりがあっても役に立たない |
| ボタンを HTML から消すと、並びや有無を目で確かめにくい | `tests/smoke.js` でヘッダのボタンの並びと、共通ファイルが無い時の案内を全ページ確かめる |

採らなかった案: 読み込み確認を別ファイルにする(共通ファイルが読めない時はそのファイルも読めないため、HTML に直接書くしかない)。

## 構成

- `common/site.js`: `addHeaderButton(id, 名前, アイコン, 前の要素, 吹き出しか)` でヘッダの4つのボタンを作る。
- 各ページの HTML: ヘッダは「アイコン・h1(・設定ボタン)」だけ。読み込み確認は `site.js`・`tool-kit.js` の直後に1つ。

## 仕様

- ヘッダの並び: (戻る)・アイコン・h1・(設定)・環境情報・カラーテーマ・テーマ・デバッグ。戻るは `tool-kit.js`、設定は HTML、残りは `site.js`。
- ボタンの名前(`data-log`・`title`・`aria-label`): テーマ・カラーテーマ・環境情報・デバッグ。テーマの `title` と `aria-label` は状態で書き換える(`data-log` は固定)。
- 読み込み確認: ツールは `window.ToolKit && window.ToolKit.media`(`device.js` まで読めたか。[device.md](./device.md))、ランチャーと一覧は `window.log` が無い時、`<body>` の先頭に「共通ファイル(common/)を読み込めませんでした。https で配信したページ(または http://127.0.0.1 のローカルサーバー)で開いてください。」を出す。色は `site.css` が無くても読めるよう直接書く。

## ヘッダを隠すページ(2026-11-07 追加)

画面いっぱいに使うページ(DJターンテーブル Pro・3D本棚ランチャー)は、ヘッダを画面の上に隠し、右上の小さなつまみで出す。初めは DJ Pro の中だけに作ったが、2つ目のページが使うので共通にした。

- 使い方: `<html lang="ja" class="bar-hidden">` と書くだけ。つまみは `site.js` が足す(HTML に書かない)。
- 動き: つまみを押すとヘッダが下りてきて、つまみはヘッダの下へ動く。本文(`main`)に触る・つまみをもう一度押す・Escape で隠れる。埋め込み表示(`?embed=1`)ではつまみを出さない。
- 見た目: ヘッダは `position: fixed` で上に隠れ、本文は画面の上の端から使える。つまみは半透明の暗い色(どの画面の上でも見える)。ページの CSS で色だけ変えてよい(DJ Pro は機械の色)。
- 名前: つまみの `data-log` は「メニュー」、`aria-expanded` で開閉を表す。

## 処理の流れ

1. `site.js` が `.site-bar` を探し、テーマ・デバッグのボタンを末尾に足す。
2. カラーテーマをテーマの前に、環境情報をカラーテーマの前に足す。
3. 読み込み確認は、共通ファイルが読めた時は何もしない。

## 制限事項

- 共通ファイルが無い時、ツールの js は最初の `log(…)` で止まり、コンソールにエラーが出る(画面の案内で原因はわかる)。
- `env.js` だけが読めない時は環境情報のボタンを出さない(これまでどおり)。

## 確認

- `node tests/smoke.js all`: 全ページでボタンの並び、テーマの切り替え、環境情報、共通ファイルを止めた時の案内(ヘッダを隠すページは、先につまみを押す)。
- ヘッダを隠すページ: 3D本棚でつまみを押して出る・本棚に触って隠れることを開発環境で確かめた(2026-11-07)。実機は未確認。
