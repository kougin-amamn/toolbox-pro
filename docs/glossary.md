# 用語集

設計書と文書で使う言葉です。同じ物を別の言葉で呼ばないために置きます。新しい言葉を使い始めたら、ここに足します。

| 言葉 | 意味 |
| --- | --- |
| ツール | `tools/<slug>/` にある、1つの用事のためのページ |
| slug | ツールのフォルダ名とファイル名の元になる英語の名前(`file-transfer`) |
| ランチャー | ツールを選んで開く入口の画面(`launchers/`)。本棚・美術館・デスクトップ |
| 一覧 | ツールの一覧データ `index-data.json`。画面の「2D の一覧」とは別 |
| 2D の一覧 | 3D ランチャーの中の、ツールを文字で並べた画面。3D が使えない時の代わり |
| 共通部品 | 全ページで使う `common/` のファイル |
| core | 画面を持たない計算だけのファイル(`<slug>-core.js`)。Node で試す |
| トークン | 色や大きさを名前で表した値(`--accent` など)。色は必ずこれを使う |
| 段 | 大きな作り変えを分けた1回分(段 1a・段 2)。1段ずつ push する |
| 要確認 | 実機で確かめていない事 |
| AI が決めた事 | 人に聞かずに AI が決め、理由を残した事 |
| 要件番号・試験番号 | `R-01`(できないといけない事)と `T-01`(それを確かめる試験)。試験の名前にも書く |
| 土台(stage) | 3D の描き手・描画の繰り返し・大きさ合わせをまとめた部品 |
| 描画の環境の喪失 | WebGL のコンテキストが失われること(iPhone で裏に回した後など) |
| 画質の段 | 3D の重さを端末に合わせる段(低・標準・高) |
